Features

Everything you need, nothing you don't

A focused writing experience with the niceties of a modern editor — no mouse required.

📝

Smart editor

Separate title and body fields with Tab to switch. Insert timestamps and bold markers with a keystroke.

💾

Autosave

Changes are written to disk automatically as Markdown. The note title becomes the filename — your notes are plain files, forever.

👀

Live Markdown preview

Toggle a styled preview of headings, bold, italic, code, lists, and quotes.

📚

Paginated list

Browse all your notes, newest first, in a clean paginated list that scales to your terminal.

🔍

Search everywhere

Filter the list by title and content, and search for words inside a note with highlighting and jump-to-next.

🗑️

Safe delete

Remove notes from the list with a confirmation prompt, so nothing disappears by accident.

📊

Live stats

Word count, character count, and cursor line/column update as you type.

🎨

Modern look

A Catppuccin-inspired theme with rounded borders, gradients, and clickable links.

⚡

Cross-platform

Single self-contained binary for Linux, macOS, and Windows. No runtime, no dependencies.

Installation

Up and running in seconds

Pick your platform. The easiest options need no Go and no build step.

One-line install

Detects your OS/architecture, downloads the latest release, and puts th-note on your PATH.

$ curl -fsSL https://raw.githubusercontent.com/tanzid64/th-note/main/install.sh | sh

Then just run:

$ th-note

Download & run

Grab th-note_windows_amd64.zip from the latest release, unzip it, and run th-note.exe. Place it in a folder on your PATH to run it from anywhere.

PS> iwr https://github.com/tanzid64/th-note/releases/latest/download/th-note_windows_amd64.zip -OutFile th-note.zip ; Expand-Archive th-note.zip

💡 Use Windows Terminal so the colors, logo, and emoji render correctly.

Install with Go

If you have Go 1.26+, this builds and installs the binary into your Go bin directory.

$ go install github.com/tanzid64/th-note@latest

Make sure $(go env GOPATH)/bin is on your PATH.

Download a binary

Pre-built binaries are published for every release. No Go required to run them.

Build it yourself

Clone the repo and build with Go or the Makefile.

$ git clone https://github.com/tanzid64/th-note.git
$ cd th-note
$ make build   # → ./th-note
